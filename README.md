## L.E.A.P. — Linux Enumeration and Persistence Framework

> A stealthy, modular Bash framework for post-exploitation on Linux systems.

| Module | What it does |
|---|---|
| Reconnaissance | Kernel, OS config, env vars, interpreters, shell accounts |
| Enumeration | SUID/SGID binaries, writable paths, capability misconfigs, SSH key leaks, Bash history credentials |
| Network Audit | Listening services, ARP caches, egress port mapping, reverse shell payload generation |
| Container Detection | Docker / LXC / K8s runtime detection, privileged escape vector evaluation |
| Exfiltration | In-memory loot compression via `/dev/shm`, async C2 streaming over Netcat or curl |
| Stealth Cleanup | Log sanitization, history trimming, timestamp restoration, artifact shredding |
